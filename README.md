## 👋 About Me

I'm constantly leveling up my skills and love turning complex problems into simple, beautiful solutions.

- 🛠️ Building projects with **React** and **Tailwind CSS** for clean, fast UIs
- 📘 Strengthening my **TypeScript** skills for more reliable, scalable code
- 🎯 Focusing on **performance optimization** and **accessibility** in web apps
- 💬 Ask me anything about **React**, **Next.js**, **Tailwind**, or **JavaScript**
